How it works

  1. On the child's phone, tap Forgot PIN. It shows an 8-digit number.
  2. Type that number and your recovery key above.
  3. Type the code you get on the phone. Then set a new PIN.

Each number works once. After 3 wrong codes the phone shows a new number — just type the new one here.
